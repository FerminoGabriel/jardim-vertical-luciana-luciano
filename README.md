# Jardim vertical — Luciana & Luciano

Visualizador Three.js do jardim, arquitetura em camadas, estrutura, iluminação e instalações.

Malha de 19 × 14 com uma abertura de serviço (265 módulos), 26 luminárias em quatro faixas alternadas, dois pontos de água com torneiras e elétrica embutida.

Estudo geométrico para análise: detalhes não cotados pelos fabricantes são aproximações. Não substitui os projetos executivos de estrutura, elétrica, hidráulica ou iluminação.
